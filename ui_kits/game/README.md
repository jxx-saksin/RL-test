# Game UI Kit — RL Extraction

Composed, high-fidelity mobile screens built from the design-system tokens and components.

- `S2-safehouse.html` — 안전가옥 허브 (central hub): character summary (HP / STA / Sato balance), menu list, out-counter, bottom tab nav. The disguise in action — reads like a banking/productivity home.
- `S4-combat.html` — 전투 로그 (the heart): sticky resource header (enemy HP + player HP/STA + timer), scrolling turn-grouped mono log with inline damage/crit/heal/status/growth tokens, and the between-fight 3-button decision UI (다음 전투 / 회복하기 / 귀환·도망).
- `index.html` — both screens side by side.

All link the root `styles.css`. Icons via Lucide CDN. Fonts are the temporary IBM Plex placeholders.
