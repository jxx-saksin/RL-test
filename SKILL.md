Read `readme.md` first, then explore `styles.css` + `tokens/` for the exact color/type/spacing tokens, `guidelines/` and `components/` for foundation and component specimens, and `ui_kits/game/` for composed screens.

Core tone: an ordinary-looking daily app (productivity × finance) that keeps the books on survival in a cold near-future apocalypse. No game chrome, no rarity color, no emoji. Dark near-black neutral base (hue ~264), muted ink accents, mono for all data/logs and numbers, sans for language. Mobile-first portrait.

If creating visual artifacts (mocks, throwaway prototypes, screens), copy assets/tokens out and build static HTML linking `styles.css`. If working on production code, read the rules here to design as an expert in this brand.

If invoked without guidance, ask what to build, then act as an expert designer producing HTML artifacts or production code as needed. Note: the two fonts are temporary placeholders pending client-supplied EN/number/KR fonts.
